# SmartLearn User Guide

Welcome to SmartLearn! This guide will help you get started using the platform.

---

## 🚀 Getting Started

### For New Users

1. **Go to the Application**
   - Open your browser
   - Visit: http://localhost:5173

2. **You'll See the Login Page**
   - Enter email and password
   - Click "Sign In"

3. **Don't Have an Account?**
   - Click "Register here"
   - Fill in your information
   - Select your role (Student or Teacher)
   - Create your account

---

## 📝 Registration

### Step-by-Step

1. **Click "Register here"** on the login page

2. **Fill in Your Information**
   - **Full Name**: Your complete name
   - **Email Address**: Valid email (for login)
   - **Role**: Select one:
     - **Student**: If you want to learn
     - **Teacher**: If you want to teach
   - **Password**: At least 8 characters
   - **Confirm Password**: Must match password

3. **Click "Create Account"**

4. **Automatic Redirect**
   - Students → Student Dashboard
   - Teachers → Teacher Dashboard

### Password Requirements
- ✅ At least 8 characters
- ✅ Can contain: letters, numbers, special characters
- ✅ Confirm must match exactly

---

## 🔐 Login

### For Existing Users

1. **Click "Sign In"** (or go to login page)

2. **Enter Your Credentials**

4. **You're In!**
   - You'll see your dashboard

## 🐛 Troubleshooting

### Can't Login?
1. Check your email is correct
2. Check your password is correct
3. Make sure you registered first
4. Refresh the page and try again

### Page Not Loading?
1. Check internet connection
2. Refresh the page (F5)
3. Clear browser cache
4. Try a different browser

### Dashboard Not Showing?
1. Make sure you're logged in
2. Check if page is loading
3. Refresh the page
4. Check browser console (F12) for errors

### Can't See My Course?
1. You might not be enrolled
2. Contact your teacher
3. Wait for enrollment approval
